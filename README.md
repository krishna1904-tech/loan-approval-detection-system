# 🏦 Loan Approval Prediction System

A Machine Learning web application built with **Python**, **Scikit-learn**, and **Streamlit** that predicts whether a loan application is likely to be **Approved** or **Rejected** based on applicant information.

---

## 📌 Features

- Predict Loan Approval Status
- User-friendly Streamlit Interface
- Automatic Data Preprocessing
- Missing Value Handling
- Label Encoding
- Random Forest Classification Model
- Model Accuracy Display
- Confusion Matrix
- Loan Approval Distribution Chart
- Correlation Heatmap

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/LoanApprovalPrediction.git
```

Go to the project folder:

```bash
cd LoanApprovalPrediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

The application will open automatically in your browser.
